# SceneForge AI — 2D Animation Production Studio

A local-first web app for producing original 2–5 minute 2D cartoon / anime-style videos with a
semi-automatic, approval-gated pipeline:

```
IDEA → SCRIPT → SCENE BREAKDOWN → CHARACTER REFERENCES → STORYBOARD → AUDIO → ANIMATION → TIMELINE → FINAL REVIEW → EXPORT
```

It mixes **cheap limited 2D animation** (layered sprites + programmatic motion in Remotion) with
**selective AI image-to-video** shots and **stills**, per shot, under a hard monthly budget.

> **Phase 1 status:** the full local studio works end to end with **mock and free local providers only**.
> No paid API is implemented or called. See [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md).

## Requirements

| Tool | Version tested | Notes |
|---|---|---|
| Node.js | 22.x (≥ 20.11) | |
| FFmpeg + ffprobe | 6.1 | required (mixing, probing, encoding) |
| Chrome headless shell | Playwright 1243 build | auto-detected; otherwise Remotion downloads its own on first render |
| eSpeak NG | 1.51 | **optional** free offline voice (`apt install espeak-ng`); falls back to a mock voice |

Linux/macOS. 4+ CPU cores recommended (a 2-minute 1080p export renders in ~8–10 min on 4 cores).

## Setup

```bash
cd sceneforge
npm install
cp .env.example .env.local     # optional; defaults are mock-mode
npm run db:init                # creates data/sceneforge.db and prints the detected environment
```

## Run

```bash
npm run build
npm start          # web app on http://localhost:3000 + background worker (logs in data/run/)
npm stop
```

Development: `scripts/start.sh --dev` (Next dev server + worker), or run `npm run dev` and `npm run worker` in two terminals.
The **worker must be running** for generation jobs, storyboard frames, previews and exports.

## Demo project (no paid calls)

```bash
npm run demo:seed     # builds the demo library + "The Lantern Courier" through every checkpoint (~80 s)
npm run demo:render   # final review + full 1080p export (~9 min on 4 cores)
npm run demo:preview 2  # optional: half-res preview of scene 2
```

The demo library contains 3 original characters (layered rigs: 3 poses, 6 expressions, blink, 3 mouth
shapes), 4 layered parallax environments + a sunset lighting variant, and original procedural
music/ambience/SFX — all generated by code in `lib/demo/`, so the demo has no licensing questions.
In the UI, **Projects → Create demo project** builds an interactive copy that you take through the
checkpoints yourself.

Exports land in `data/exports/<projectId>/<exportId>/`: `final.mp4`, `final.srt`, `scene-NN.mp4`, `manifest.json`.

## Tests

## Using the studio

1. **New project** — title, genre preset, 16:9 or 9:16, 120–300 s target, budget cap, optional series.
   Input an idea (template draft, no AI key needed) or a full script (`.txt/.md/.fountain` upload works).
2. **Story** — edit scenes, beats, action lines and dialogue (speaker, emotion, speed). Runtime is estimated from
   speech rate per emotion, pauses, actions and transitions. Edit the project's own **Style Bible**. → *Checkpoint 1*.
3. **Characters & Art** — build the cast from the shared **Character Library**; in the Character Studio upload
   turnaround views / references / layered rig sprites, approve, fill the continuity checklist and lock. Assign
   environments to scenes. → *Checkpoint 2* (blocked until every cast member is locked and every scene has an environment).
4. **Storyboard** — plan shots from the script (establishing / dialogue / action shots, framing, camera moves,
   effects, mode A/B/C by your mix ratio). Edit, duplicate, reorder, approve/reject shots; render storyboard
   frames. → *Checkpoint 3* (shows estimated AI cost).
5. **Audio** — generate voices per line (eSpeak NG free, or mock), regenerate a single line, import recordings,
   per-scene music/ambience.
6. **Animation** — request start images / image-to-video for Mode B (stills for Mode C). Jobs wait in
   **Checkpoint 4**: approve an exact batch (cost reserved in the ledger). Review takes; approve, reject, revert,
   or replace with your own footage.
7. **Editor** — live Remotion preview, multi-track view (video, background, dialogue, music, ambience, SFX,
   subtitles), clip trim/duration/transition/reorder, track volumes/mute/ducking, burn-in subtitles.
8. **Review & Export** — *Checkpoint 5* approves an exact timeline version; export the final MP4 + SRT + scene
   files + manifest, or half-res previews (whole film or per scene).

## Licensing notes

- **Remotion** (v4.0.540, per its bundled `LICENSE.md`): free for individuals, for-profit organizations with up to
  3 employees, and non-profits; larger for-profit companies need a Company License (remotion.pro). Re-check when
  upgrading — the license notes changes planned for Remotion 5.
- Only use original, owned or properly licensed artwork, voices, music and footage. Imported assets record
  provenance; exports include a manifest listing every asset used and whether any mock content is present.
